## CLM-0164. Three necessary profiles for a Fano-eligible P26
Let H=C10^3, K=2H≅C5^3, Q=H/K≅F2^3. Let P be any indexed zero-sumfree length26 sequence in H. Write z for the number of P indices of quotient class 0 and r for the number of the seven nonzero quotient classes with ODD indexed multiplicity. Let E(P)={x in H: P*x zero-sumfree}. If the affine span of the mod2 image of E(P) equals all Q, then
**(z,r) belongs to {(0,4),(0,6),(1,7)}.**
Thus every hypothetical S58 satisfying the corrected S042 CLM-0158/0159 must admit a canonical 26-pair P with one of just these three multiplicity profiles. This is a necessary structural gate, not an exclusion of the surviving profiles.

Proof with ALL original indices. Each zero-class P index itself forms a quotient-zero singleton. Within each nonzero value class, pair DISTINCT indexed occurrences; this gives (26-z-r)/2 disjoint quotient-zero pairs. There remain r distinct nonzero unpaired residues. Thus B=(26+z-r)/2 disjoint quotient-zero blocks. If B≥13, the corresponding thirteen H-kernel decorations belong to C5^3 and D(C5^3)=13 gives a nonempty subcollection with sum0: its indexed union is a forbidden H-zero sum. Hence r≥z+2. Because 26-z-r is even, r-z is even and positive, and r≤7.

**Case r=z+2 (B=12).** Appending x in class0 adds a quotient-zero singleton; appending x in any of the r odd nonzero classes adds a new disjoint equal-class pair. Either yields13 and is forbidden. Hence bar E lies among the 7-r even nonzero classes. For z≥2, r≥4, so 7-r≤3 and affine span has dimension≤2. For z=1,r=3: the three odd residual vectors a,b,c cannot sum to0, since then their whole triple alongside the existing12 blocks would furnish13. The nonzero vector d=a+b+c is distinct from a,b,c and among the four even nonzero classes. Adding x of quotient class d gives four residual nonzero vectors summing0, a thirteenth block, hence is forbidden. At most three extension quotient classes remain. For z=0,r=2, let odd classes be a,b distinct. In addition to a,b and0, class a+b is forbidden because the residual a,b,a+b triple is a quotient zero; the four remaining classes are exactly the affine coset Q\span{a,b}, of affine dimension2. Thus full affine span is impossible for ALL r=z+2 cases.

**Case r=z+4 (B=11).** If bar x=0 then 12 singleton/pair blocks remain and at least r≥4 distinct nonzero residual vectors: any four in the three-dimensional F2 space are linearly dependent, and no singleton or pair of distinct nonzero vectors sums to0, so there is another disjoint quotient zero block. If bar x is one of the r odd classes, there are12 singleton/pair blocks and r−1 residual distinct nonzero values; for r≥5 these contain a zero subset, again giving13 blocks. Thus for z≥1 only the 7-r even nonzero classes can support extensions. At z=1,r=5, there are only two, so affine span≤1. At z=2,r=6, the only missing nonzero class d would make ALL seven nonzero classes odd after appending x. The seven residual classes split into an Fano zero triple and its complementary zero quadruple (their total is zero), and together with the eleven singleton/pair blocks yield13. Thus E(P)=empty for (2,6). At z=3,r=7 there are no even nonzero classes, so E(P)=empty. Only z=0,r=4 is not excluded in this case.

**Case r≥z+6.** Since r≤7, the only possibilities are (0,6) and (1,7). These are not ruled out by this argument.

This exhausts the options. Every counted block is index-disjoint; no repeated value was collapsed into one index. All lift contradictions use thirteen disjoint Q-zero blocks, whose H-kernel decorations have zero-sum by proved D(C5^3)=13. Neither source-stated D(C10^3)=28 nor an inverse classification was invoked to prove this local gate. Application to an actual S58 additionally requires S041/S042 Fano canonical setup, whose C10 endpoint remains historically SOURCE_STATED.
