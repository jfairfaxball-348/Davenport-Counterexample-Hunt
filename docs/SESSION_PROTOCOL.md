# One-session protocol

## Entry
1. Pin live remote main SHA; compare with previous closeout. List open/recent merged PRs and actual GitHub Actions runs/jobs; record absent workflows without inventing passes.
2. Confirm session number uniqueness and no intervening changes. Read all authority, target, source, claim, frontier, campaign, and previous closeout documents.
3. Archive the exact incoming owner invocation in sessions/S###/INPUT.md (future sessions); include a SHA-256 in INPUT_MANIFEST.json where exact bytes are accessible. Do not claim a verbatim archival hash when input capture is incomplete.
4. Pre-register a bounded work plan, allowable proofs and stopping rule. Do not run more than one session or a future prompt.

## Work
Keep literature source statements, proofs, reproducible computations, heuristics and formal verification distinct. Every computation includes script, inputs, environment, exact output SHA-256 and, if exhaustive, completeness justification. Proofs must include assumptions and complete arguments. Every candidate is quarantined.

## Gate
Phase 0 governance -> Phase 1 frontier -> Phase 2 certified tooling -> Phase 3 campaigns, with owner-gated Phase 4 results; next phase only after explicit committed PASS review. Phase 1 status is not equivalent to a resolved rank-three case.

## Close
Synchronize claims, sources, frontier, campaign registry, state, decisions, failure ledger and session ledger. Include outcome, evidence categories, checks actually run, hashes/commit refs and limitations in sessions/S###/CLOSEOUT.md. Draft full next prompt only if no owner/external blocker. Exactly one atomic session branch commit, push, merge without force, independently pin remote main. If blocked, report precise owner action and withhold next prompt. Stop.
